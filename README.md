# Handy Racks — Custom Furniture & Commercial Display Showcase

Developed by **Harsh Apex Digital Solutions**.

## Stack
- Next.js 15 (App Router)
- React 18 & TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger & Motion for React
- Lucide Icons

## Local Development & Vercel Deployment
```bash
npm install
npm run dev
```

To create a production build:
```bash
npm run build
npm start
```

Deploy directly to Vercel by importing this directory as a Next.js project.
